Security model

  • File content is encrypted with AES-256-GCM using a random file key.
  • The file key is wrapped for the user passphrase.
  • If Master recovery is active in Settings, the file key is also wrapped automatically for Master recovery using ML-KEM-768.
  • The server stores encrypted Vault packages and cannot generate thumbnails or content previews for them.
