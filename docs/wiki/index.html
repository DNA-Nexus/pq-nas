DNA-Nexus Wiki

This wiki explains how to install, configure and manage a DNA-Nexus server. It is written for administrators, support staff and technical partners who need clear step-by-step instructions.

Server installation

Start here when setting up a new DNA-Nexus server from scratch.

First login

Create new users, approve accounts and explain the first-use flow.

File Manager

Common issues

Collect installation problems, login problems, disk issues and browser-side fixes.

Recommended documentation style

Each page should explain one task. Use short sections, screenshots, warnings and success checks. The goal is that a new administrator can follow the page without already knowing how DNA-Nexus works.

Page type Use it for Typical structure
How-to guide Installing, creating users, adding disks Prerequisites → Steps → Verification → Troubleshooting
Reference page Settings, permissions, roles, storage states Overview → Field list → Examples → Notes
Troubleshooting page Known problems and fixes Symptom → Cause → Fix → Prevention
