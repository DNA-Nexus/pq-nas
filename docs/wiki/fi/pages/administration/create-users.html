Käyttäjien luominen

Status: Draft Audience: Administrator / Support

This page explains how an administrator creates or approves DNA-Nexus user accounts.

Recommended user lifecycle

  1. Create or receive a user registration

    The user account may be created by an administrator or requested by the user from the login page.

  2. Review user details

    Check the username, display name, role and intended storage quota.

  3. Approve the user

    Approve the user when the account is ready to access the server.

    Screenshot placeholder: Admin approval view.

  4. Tell the user to sign in

    After approval, the user can sign in and start using DNA-Nexus apps.

  5. Tapa 3: Käyttäjien lisääminen password-auth-tunnistuksella

Fields to document

Field Meaning Example
Username Unique login name. alice
Display name Name shown in the user interface. Alice Example
Role User permission level. User / Admin
Storage quota Maximum storage assigned to the user. 100 GB

Tapa 3: Käyttäjien lisääminen password-auth-tunnistuksella

Kun käytössä on perinteinen käyttäjätunnus/salasana-kirjautuminen, uusia käyttäjiä luodaan kohdasta Ylläpito → Asetukset. Avaa kortti Tietoturva • Luo salasanakäyttäjä.

Täytä uuden käyttäjän nimi ja kirjautumistunnus / sähköposti. Valitse sen jälkeen:

  • Rooli – tavallisesti käyttäjä tai ylläpitäjä.
  • Tila – normaalissa käytössä joko pois käytöstä — vaatii hyväksynnän tai käytössä — voi kirjautua heti.
  • Kiintiö tavuina – valinnainen säilytystilan varaus. Sen voi määrittää tai muuttaa myös myöhemmin Käyttäjäprofiilit-näkymässä.
Huomio tilasta: Jos omassa buildissäsi näkyy lisäksi jokin odottaa-/pending-tyylinen tila, käsittele sitä toistaiseksi valinnaisena siirtymätilana. Useimmissa tapauksissa on yksinkertaisinta käyttää joko pois käytöstä tai käytössä.

Kun ylläpitäjä painaa Luo käyttöönotto­linkki -painiketta, DNA-Nexus luo kertakäyttöisen setup-/käyttöönotto­linkin. Ylläpitäjä kopioi tämän linkin ja toimittaa sen turvallisesti uudelle käyttäjälle.

Uusi käyttäjä avaa linkin ja viimeistelee tilin valitsemalla itselleen salasanan.

Kun salasanan asetus onnistuu, DNA-Nexus näyttää käyttäjälle tilin luomisessa muodostetut tiedot: sormenjäljen sekä 24 palautussanaa.

Tärkeää: 24 palautussanaa näytetään vain kerran, eikä palvelin tallenna niitä. Käyttäjän on kopioitava ja tallennettava sanat turvalliseen paikkaan ennen sivulta poistumista. Kuka tahansa näillä sanoilla voi palauttaa kyseisen DNA-identiteetin.

Kun käyttöönotto on valmis, tili ilmestyy normaaleihin käyttäjähallinnan näkymiin. Jos tili luotiin pois käytöstä -tilassa, käyttäjä tarvitsee vielä ylläpitäjän hyväksynnän tai aktivoinnin ennen kuin kirjautuminen onnistuu.
