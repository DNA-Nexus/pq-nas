First login

Status: Draft Audience: Administrator

Use this page after the server installation is complete and the DNA-Nexus web interface is reachable.

  1. Open the login page

    Open the DNA-Nexus server address in your browser.

    Screenshot placeholder: Login page.

  2. Sign in as administrator

    Use the initial administrator credentials created during installation or provided by the installer.

  3. Check the dashboard

    Confirm that the dashboard opens and there are no critical alerts.

    Screenshot placeholder: Dashboard after first login.

  4. Review server settings

    Open the settings page and verify language, server name, storage paths and security settings.
