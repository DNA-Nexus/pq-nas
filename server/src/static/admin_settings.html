This Master recovery key protects only this signed-in admin account's own Vault uploads. It is not a service-wide master key and it does not give this admin account access to other users' or other admins' Vault files.

Uploads & Tiering Help

Upload tiering lets new uploads land in a fast internal pool first and later migrate to capacity storage.

Landing storage
Select an internal pool for landing. USB and removable pools are automatically blocked for safety.

Migration worker
Worker interval controls how often the worker wakes up. Minimum landing age controls how old a file must be before it can be moved. Max files per pass controls how many eligible files are moved during one worker pass.

Upload tiering is not a backup feature. It only controls where new uploads land first and how they are later moved.
