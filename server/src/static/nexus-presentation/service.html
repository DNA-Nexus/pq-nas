Service

More than storage. A cloud service for real work.

DNA-Nexus is built as an expandable cloud application platform. The user experience feels familiar, but the service can include much more than basic file sync.

UX

Simple for users

Files, photos, music, bookmarks, shares and upload links are available from one browser-based interface.

BR

Useful for businesses

Customer uploads, branded intake pages, workspaces and activity tracking make the service practical for daily operations.

OP

Valuable for operators

A local cloud service can offer trust, support and feature depth instead of only generic storage capacity.

Application platform

Integrated apps under one service.

DNA-Nexus can include file management, secure sharing, photo galleries, music playback, bookmarks, web archiving, external upload links, branded customer upload pages, social sharing, audit logs, backups, system monitoring and more.

  • New apps can be added without sending users to separate services.
  • Users get one consistent cloud environment.
  • The service can be packaged for homes, businesses, clubs and organizations.
