Features

Useful cloud tools in one place.

DNA-Nexus combines familiar file storage with advanced utility: versioning, secure links, customer upload portals, photo management, music playback, web archiving and social sharing.

File Manager

A modern file workspace.

Users can upload, download, organize, favorite and share files from a clear cloud-style interface. Built-in versioning helps protect against accidental overwrites.

  • View, download, restore, delete or mark older versions as important.
  • Recover deleted files from trash for 30 days.
  • Collaborate through shared workspaces with internal or external users.
SH

Secure sharing

Create share links with expiration times such as 1 hour, 24 hours, 7 days or no expiration. Links can be named, managed later and tracked by open count.

PQ

Protected access

For more sensitive use cases, protected sharing links can require recipient authentication before access.

Drop Zone

Professional customer file intake.

Drop Zone creates one-way upload links for external users. The sender only sees an upload page and cannot browse, download, rename or delete anything.

  • Set maximum file size, total upload limit, target folder, expiration and password protection.
  • Use branded pages with company name, logo, instructions, colors and button text.
  • Create templates for accounting material, media delivery, support files or secure document intake.
PG

Photo Gallery

Browse photos, adjust thumbnails, mark favorites, rate images, search metadata, share albums, use map view and compare images side by side with synchronized zoom.

NW

NeonWave

Play music stored in the service, create playlists, use shuffle or repeat, mark favorites, view listening history, use a sleep timer, visualizer modes and a six-band equalizer.

ES

Echo Stack

Save links, organize collections, add tags and notes, mark items as read or unread and archive web pages for later viewing.

CS

Circle Stack

Share photos, videos, files, albums and posts into a feed. Private posts can also work as a personal visual journal.
